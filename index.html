Alicanto Base Protocol

Review the operational capabilities of the Stacker and Macro Pro deployments.

🥈 STACKER TIER
The Reality: This is a read-only tier. It allows a user to ask the bot basic questions and view the current live market data, but it strictly locks them out of any advanced analysis, memory training, or the web dashboard.

Market Data Access

Users can run /price, /ratio, /status, and /defcon to see the live metrics (COMEX, Shanghai spread, GSR, and threat levels).

Strict Constraints

  • Chat Limits (Strict): They can only send 10 messages per hour to the AI.
  • Context Limits (Strict): Their messages are hard-capped at 150 words. If they type more, the bot rejects it.

What is Locked 🔒

Stacker users are actively blocked by the premium_triggers gatekeeper. If they try to use /brief, /inject, /clear, /alert, /connect, or /query, the bot denies access. They do not get access to the visual Web Terminal link.

Deploy Stacker
🥇 MACRO PRO TIER
The Reality: This tier unlocks the full RAG (Retrieval-Augmented Generation) engine. It changes the bot from a simple price-checker into a programmable research assistant. Pro users can actively alter the bot's memory, set background triggers, and use the graphical dashboard.

Expanded Limits

The chat limit increases to 30 messages per hour, and the input limit increases to 250 words per message, allowing them to paste in larger chunks of text for analysis.

Deep Research Tools

  • Web Terminal Access: Pro users get the 🌐 Open Terminal button, which passes a secure PIN to open the Flask-powered visual dashboard (showing the live arbitrage chart, data grid, and dark pool ticker).
  • Automated Briefings: They can run /brief once every 4 hours to force the LLM to synthesize the latest news into an executive summary. They automatically receive a push-notification briefing every Friday at 5:00 PM.
  • Custom Alerts (/alert): They can set up to 4 active triggers per day (e.g., /alert price 35 or /alert keyword shortage). The background loop will ping them when those conditions are met.
  • Memory Injection: They can feed private notes or data directly into the AI's vault via /inject so it gets included in future summaries.
  • Query & Connect: They can search the vector database 10 times a day (/query) and generate up to 5 "Contagion Maps" a day (/connect).
Deploy Macro Pro
The Bottom Line: Stacker pays for basic API calls to check prices and ask simple questions. Pro pays for the computing power required to run continuous background tasks (alerts), vector database searches (queries), and large-token context summaries (briefings).
